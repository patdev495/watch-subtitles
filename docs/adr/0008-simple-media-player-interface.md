# Simple media player interface

The previous Titanium Zinc monochrome direction gave Watch Subtitles a dark professional-tool appearance, but the agreed goal is a simpler desktop media-player interface inspired by Windows Media Player Legacy. We will keep Video central and preserve existing workflows while making light the default, using compact flat surfaces and a restrained blue accent in both themes. This supersedes ADR-0007's visual direction; the existing subtitle presentation stays because it is already readable over Video.
